# templates/

One HTML page each, filled in by the routes in `dashboard.py`. Each file
starts with a comment saying what it shows.

| File | Page | What it does |
| --- | --- | --- |
| `advisor.html` | `/advisor` | Buyer Fit-Out Advisor: keep, opt out or upgrade each fitting, with live savings and the 3D home |
| `dashboard.html` | `/dashboard` | SDP dashboard: KPIs, rip-out chart, "what to change next launch", upgrade mix, 3D home |
| `match.html` | `/match` | Neighbour Match: animated map of removed fittings going to neighbours |
| `simulate.html` | `/simulate` | What-if: sliders that project a whole launch |
| `tagger.html` | `/tagger` | AI tagging: sort a messy renovation note into fittings and save it as a report |
| `_topbar.html` | (every page) | The shared logo and page menu, included at the top of each page |
