How matching works

Simple rules, so it can run inside SDP's existing owner app or portal.

  1. An owner lists a fittingSomething they're removing anyway, with photos and its condition. Tiles and toilets aren't listed: hacked-out tiles break, and toilets aren't reused for hygiene reasons.
  2. Only the same home typeSame design, same measurements, so it fits with no measuring or rework.
  3. Nearest owner firstShort trips keep transport low. Each trip's carbon ({{ trip_factor }} kg CO₂e per km, both ways) is taken off the saving.
